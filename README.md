# ai-process/.github

Organization profile for [github.com/ai-process](https://github.com/ai-process).

- `profile/README.md` — the text shown on the organization page.
- `assets/banner.html` — source of the banner; `scripts/render.sh` renders it to `assets/banner.png` with headless Chrome.
- `assets/avatar.png` — organization avatar (512×512), rendered from `assets/logo.svg`.
